# Ретранслятор заявок в Telegram

Сайт статический, его JavaScript открыт всем, а репозиторий публичный — токен бота
туда класть нельзя, иначе писать от имени бота сможет кто угодно. Ретранслятор
решает это: токен хранится у него, сайт знает только адрес.

```
форма на сайте  →  ретранслятор (хранит токен)  →  ваш Telegram
```

Выберите **один** вариант: Google Apps Script (проще, ничего не регистрировать
кроме Google-аккаунта) или Deno Deploy.

## Шаг 1. Создать бота — 2 минуты

1. В Telegram напишите [@BotFather](https://t.me/BotFather) команду `/newbot`.
2. Задайте имя и юзернейм бота (юзернейм должен оканчиваться на `bot`).
3. BotFather пришлёт **токен** вида `8123456789:AAH...`. Никому его не показывайте
   и не коммитьте в репозиторий.
4. **Откройте чат со своим ботом и нажмите «Старт»** — без этого бот не сможет вам писать.

## Шаг 2. Узнать свой chat id

Напишите [@userinfobot](https://t.me/userinfobot) — он ответит вашим `Id`.
Это число и есть `CHAT_ID`.

Хотите получать заявки в группу, а не в личку: добавьте бота в группу администратором,
напишите там любое сообщение и откройте
`https://api.telegram.org/bot<ТОКЕН>/getUpdates` — в ответе будет `"chat":{"id":-100...}`.

## Шаг 3а. Google Apps Script

1. Откройте [script.google.com](https://script.google.com) → **Новый проект**.
2. Вставьте туда содержимое `apps-script.gs` (заменив код по умолчанию).
3. **Настройки проекта** (шестерёнка) → «Свойства скрипта» → добавьте два свойства:
   - `BOT_TOKEN` — токен от BotFather
   - `CHAT_ID` — ваш id
4. **Начать развёртывание** → **Новое развёртывание** → тип «Веб-приложение»:
   - «Запуск от имени»: **от моего имени**
   - «У кого есть доступ»: **у всех**
5. Скопируйте URL развёртывания — он выглядит как
   `https://script.google.com/macros/s/AKfy.../exec`.

Проверить, что живой: откройте URL в браузере, должно вернуться `{"ok":true,...}`.

## Шаг 3б. Deno Deploy (альтернатива)

1. [dash.deno.com](https://dash.deno.com) → новый проект → Playground.
2. Вставьте содержимое `deno-deploy.ts`.
3. В настройках проекта добавьте переменные окружения `BOT_TOKEN` и `CHAT_ID`.
4. Скопируйте адрес проекта (`https://<имя>.deno.dev`).

## Шаг 4. Подключить к сайту

В `data/site.json` впишите полученный адрес:

```json
"relayEndpoint": "https://script.google.com/macros/s/AKfy.../exec",
```

Пересоберите (`node build.js`) и опубликуйте. Форма начнёт отправлять заявку прямо
со страницы: человек нажимает «Отправить заявку», сообщение приходит вам в Telegram,
мессенджер у отправителя не открывается.

Пока поле пустое, работает прежний режим — кнопки WhatsApp и Telegram с готовым текстом.

## Проверка

Отправьте тестовую заявку с сайта. Если сообщение не пришло:

| Симптом | Причина |
|---|---|
| На странице «Не получилось отправить» | Неверный адрес, или развёртывание закрыто не «для всех» |
| В браузере `{"ok":false,"error":"not configured"}` | Не заданы свойства `BOT_TOKEN` / `CHAT_ID` |
| Ответ `{"ok":true}`, но сообщения нет | Не нажали «Старт» в чате с ботом, или неверный `CHAT_ID` |

## Защита от спама

В формах есть скрытое поле-ловушка: люди его не видят, а спам-боты заполняют.
Такие заявки ретранслятор молча отбрасывает. Длина полей ограничена, лишние поля
отсекаются. Если спам всё же пойдёт — смените адрес развёртывания.
